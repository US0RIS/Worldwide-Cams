Worldwide Cams Privacy

Worldwide Cams is a local public-camera verification application. It uses public camera-provider APIs, including the YouTube Data API when you configure a YouTube API key.

Credentials

Windy and YouTube API keys entered in the web interface are stored in this browser's local storage. They are sent only to the local Worldwide Cams server for requests that need the corresponding provider. The server does not write those keys into the camera registry or return them in API responses.

YouTube API data

When YouTube discovery is enabled, Worldwide Cams can temporarily store public, non-authorized API data such as video IDs, titles, channel attribution, thumbnails, live status, embeddability, and geographic metadata. Stored YouTube metadata is configured to expire before 30 days unless refreshed. Worldwide Cams does not request your YouTube account login or private YouTube data.

Review decisions

Worldwide Cams can store local review decisions about whether a discovered public broadcast is suitable for the fixed-camera layer. Those review decisions are part of Worldwide Cams, not YouTube-provided categories or endorsements.

Other providers

Caltrans, Windy, custom public sources, and future providers remain independently attributed in the interface. Worldwide Cams does not claim that a provider marker proves capture time, camera field of view, or an observed event.

Third-party services

Use of YouTube features is also subject to the YouTube Terms of Service and Google Privacy Policy. OpenStreetMap tiles and other configured camera providers are subject to their own terms and policies.

Deleting local data

You can clear provider keys from the Worldwide Cams header. Runtime candidate data is stored under data/runtime/ on the machine running the local server and can be deleted by the operator. Deleting local data does not delete anything from YouTube or another provider.
